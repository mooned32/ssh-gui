# ssh-gui

Графический менеджер SSH-туннелей на Python (PyQt6).

Позволяет хранить настройки подключения, управлять списком локальных пробросов портов (`-L`) и запускать/останавливать один постоянный SSH-процесс с туннелями из интерфейса.

## Возможности

- Настройка сервера, пользователя и пути к приватному ключу (`ssh -i`);
- Управление списком туннелей: добавление, удаление, сохранение;
- Запуск и остановка SSH-процесса одной кнопкой (▶ / ⏹);
- Автоматическое обнаружение непредвиденного завершения процесса;
- Конфигурация хранится в стандартном месте ОС (см. ниже).

## Требования

- Python **3.12 или новее**;
- Клиент OpenSSH (`ssh` должен быть доступен в `PATH`);
- [uv](https://docs.astral.sh/uv/) для управления зависимостями.

## Установка и запуск

```bash
uv sync            # создать виртуальное окружение и установить зависимости
uv run ssh-gui     # запустить приложение
```

Либо запуск напрямую:

```bash
.venv/bin/ssh-gui
```

## Использование

1. В верхней панели укажите **Сервер** (адрес или IP), **Пользователь** и, при необходимости, **Ключ** (файл приватного ключа — можно выбрать кнопкой `...`).
2. Добавьте туннели кнопкой **Добавить**:
   - **Комментарий** — произвольное название;
   - **Адрес Ресурса** — удалённый хост назначения;
   - **Порт Ресурса** — удалённый порт назначения;
   - **Порт точки входа** — локальный порт, на котором будет доступен туннель.
3. Нажмите **Сохранить**, чтобы зафиксировать настройки.
4. Нажмите **▶** для запуска туннелей (кнопка сменится на **⏹** — повторное нажатие остановит процесс).

Соответствие туннелей команде `ssh`:

```
ssh -N -o ExitOnForwardFailure=yes \
    -i <ключ> \
    -L <локальный порт>:<адрес>:<порт ресурса> \
    пользователь@сервер
```

## Конфигурация

Файл `config.json`:

- Linux: `~/.config/ssh-gui/config.json` (или `$XDG_CONFIG_HOME/ssh-gui/config.json`);
- Windows: `%APPDATA%\ssh-gui\config.json`.

## Сборка автономного бинарника

```bash
uv run python build.py
```

Результат: `dist/ssh-gui` (однофайловая сборка PyInstaller, без консольного окна).
